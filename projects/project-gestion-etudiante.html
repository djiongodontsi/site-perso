Gestion étudiante avec Symfony

Centraliser les élèves, les classes, les enseignants, les cours et les notes.

Application de gestion scolaire

Une vue d’ensemble de la scolarité

Cette plateforme propose un tableau de bord qui comptabilise les élèves, les cours, les enseignants et les classes. Elle regroupe les informations pédagogiques dans une application web structurée autour de Symfony.

Fonctionnalités présentes dans le dépôt

  • Liste des élèves avec filtrage par classe, création et consultation d’une fiche.
  • Création, consultation, modification et suppression des classes et enseignants.
  • Gestion des cours à travers des écrans de liste, création et modification.
  • Création, consultation, modification et suppression des notes.
  • Tableau de bord avec les effectifs et les ressources pédagogiques.

Du modèle de données à l’interface

Le projet utilise PHP et Symfony, pour les entités et les accès aux données, et Twig pour les vues. Symfony Form structure les formulaires .

Les contrôleurs coordonnent les requêtes, les repositories interrogent les données et les entités modélisent les élèves, classes, enseignants, cours et notes. Des migrations accompagnent le modèle.

Compétences mobilisées

Architecture MVC, modélisation relationnelle, formulaires validés, opérations de gestion et restitution des données dans une interface web.
